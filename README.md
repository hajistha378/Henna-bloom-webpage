# Henna Bloom

**Blooming Beauty Through Henna**

A simple, elegant website for Henna Bloom — showcasing henna designs, services, and booking information.

## Live Website

- **Visit:** https://henna-bloom-webpage.netlify.app

## Features

- Beautiful landing page with Henna Bloom branding
- Design gallery with pricing
- Services section (Bridal, Arabic, Simple, Party Mehendi)
- Direct WhatsApp booking link
- Responsive design
